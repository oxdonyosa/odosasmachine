# odosasmachine
Real-time BTC candle consistency analyzer — scans all 15-min windows for directional bias, mirror pair correlation &amp; win rate ranking. Powered by live Binance data.
Odosa's Machine is a live Bitcoin trading analysis tool that connects 
directly to Binance to scan and rank every 15-minute candle window 
by consistency score.

Features:
- Scans all 96 daily 5 mins-1hr windows and ranks them by directional bias
- Identifies mirror pairs — windows that close in the same direction consistently
- Mon–Fri or All 7 days mode
- Your local time equivalent (WAT or any timezone) shown alongside ET
- No backend, no login — runs entirely in the browser
- Live data pulled from Binance public API

Built for serious traders who want data-driven edge, not guesswork.
